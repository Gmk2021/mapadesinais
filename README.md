# Mapa de Sinais — Netlify

Projeto preparado para publicar o Radar Mega-Sena no Netlify.

## Publicação

1. Crie um repositório no GitHub e envie todo o conteúdo desta pasta.
2. No Netlify, escolha **Add new project → Import an existing project**.
3. Selecione o repositório. O Netlify reconhecerá `netlify.toml` automaticamente.
4. Publique e teste o endereço temporário `*.netlify.app`.
5. Em **Domain management**, adicione `mapadesinais.com.br`.

Não há variáveis secretas nem dependências para instalar.
